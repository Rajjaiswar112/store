A full-stack, responsive e-commerce platform built with the MERN stack. Designed for a seamless shopping experience with secure checkout, real-time analytics, and comprehensive user management.

**🔗 Live Website:** [https://store-livid-mu.vercel.app](https://store-livid-mu.vercel.app)

---

## ✨ Key Features

* **🔐 User Authentication:** Secure login and registration flows.
* **🛒 Dynamic Shopping Cart:** Interactive cart drawer for quick order updates.
* **💳 Secure Checkout:** Fully integrated Stripe payment gateway for safe, seamless transactions.
* **📦 Product Catalog:** Detailed product view pages with high-quality layouts.
* **👤 User Profiles:** Personalized dashboards for account management.
* **📊 Analytics Tracking:** Integrated PostHog analytics for monitoring user behavior and engagement.

---

## 🛠️ Tech Stack

### Frontend
* **React.js** - UI framework
* **React Router** - Navigation
* **PostHog** - User analytics and event tracking
* Deployed on **Vercel**

### Backend
* **Node.js & Express.js** - RESTful API architecture
* **MongoDB** - NoSQL Database for scalable data storage
* **Stripe API** - Payment processing
* Deployed on **Render**
